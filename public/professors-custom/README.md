# Custom Professor Photos & App Icons Directory

Put all your professor portrait photos, custom app icons, and branding images in this directory (`/public/professors-custom/`).

### How It Works:
1. **Drop your images here**: e.g. `dr-farouk.png`, `dr-khalil.png`, `dr-ahmed.jpg`, `physics-icon.png`, `calculus-icon.webp`.
2. **Access in Code & Admin Panel**: Any image placed here is automatically accessible at `/professors-custom/filename.png`.
3. **Link via Admin Panel**: In the Admin Panel (`/admin/teachers`), you can assign any teacher to a 2-4 uppercase letter code (e.g. `VV`, `VX`, `PHYS`, `MATH`) and choose or type the path to their photo/icon from this folder.
4. **Instant Student Branding**: When students enter that code, the app icon, title, and hero banner automatically adopt that professor's identity.
