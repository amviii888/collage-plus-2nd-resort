# Custom Professor Icons & Photos Directory

Place any professor avatar or custom icon image in this folder:
`/public/icons/professors/`

Examples:
- `/icons/professors/dr-farouk.png`
- `/icons/professors/dr-ahmed.jpg`
- `/icons/professors/dr-yasser.webp`
- `/icons/professors/custom-physics.svg`

Any image placed here will be available to select in the Admin Teacher Codes & App Icons Manager (`/admin/management`) or can be referenced by typing its path directly.
